# Halden (demo prototype)

A modern fintech-style dashboard. **All balances, returns and transfers are simulated.**
No real money or cryptocurrency is handled.

## Run locally

    npm install
    npm run dev

Open http://localhost:3000

Other commands: `npm run typecheck`, `npm run lint`, `npm run build`.

## Phase 1 status
Landing, login, register and dashboard are static mockups with demo data.
Authentication, database, and real logic arrive in Phase 2+.
